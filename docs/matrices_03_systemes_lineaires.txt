COURS D'ALGEBRE LINEAIRE - CHAPITRE 3 : SYSTEMES LINEAIRES ET METHODE DE GAUSS

======================================================================
1. ECRITURE MATRICIELLE D'UN SYSTEME
======================================================================

Un systeme de m equations lineaires a n inconnues s'ecrit sous la forme AX = b, ou A est la matrice des coefficients (m x n), X le vecteur colonne des inconnues et b le vecteur colonne des seconds membres.

Systeme de reference de ce chapitre (appele systeme S) :
  x + y + z = 6
  2x - y + z = 3
  x + 2y - z = 2

Sa matrice des coefficients est A_S = [[1, 1, 1], [2, -1, 1], [1, 2, -1]] et son second membre est b = (6, 3, 2).

======================================================================
2. METHODE DU PIVOT DE GAUSS
======================================================================

Principe : on transforme la matrice augmentee [A | b] en une matrice triangulaire superieure grace a des operations elementaires sur les lignes, qui ne changent pas l'ensemble des solutions. Les trois operations autorisees sont : echanger deux lignes, multiplier une ligne par un scalaire non nul, ajouter a une ligne un multiple d'une autre ligne.

Resolution du systeme S :
- Etape 1 : L2 <- L2 - 2 x L1 donne la ligne (0, -3, -1 | -9). L3 <- L3 - L1 donne la ligne (0, 1, -2 | -4).
- Etape 2 : L3 <- 3 x L3 + L2 donne la ligne (0, 0, -7 | -21).
- Remontee : de -7z = -21 on tire z = 3. Puis -3y - z = -9 donne -3y = -6, donc y = 2. Enfin x + y + z = 6 donne x = 1.

La solution unique du systeme S est donc (x, y, z) = (1, 2, 3).

La methode de Gauss-Jordan va plus loin : elle continue jusqu'a obtenir la matrice identite a gauche, ce qui donne directement la solution et permet aussi de calculer l'inverse d'une matrice. La methode du pivot est attribuee a Carl Friedrich Gauss, mais elle etait deja connue en Chine dans le texte des Neuf Chapitres sur l'art mathematique, ecrit il y a plus de deux mille ans.

======================================================================
3. REGLE DE CRAMER
======================================================================

Si A est carree et inversible, le systeme AX = b a une solution unique donnee par x_i = det(A_i) / det(A), ou A_i est la matrice A dans laquelle la colonne i est remplacee par b.

Pour le systeme S : det(A_S) = 1 x ((-1)(-1) - 1x2) - 1 x (2x(-1) - 1x1) + 1 x (2x2 - (-1)x1) = -1 + 3 + 5 = 7. Le determinant est non nul, donc la solution est unique, ce qui confirme le resultat de Gauss.

Remarque importante : la regle de Cramer est elegante mais tres couteuse pour de grands systemes, car elle exige de calculer n+1 determinants. En pratique, on utilise Gauss ou la decomposition LU.

======================================================================
4. CLASSIFICATION DES SYSTEMES : EXISTENCE ET UNICITE
======================================================================

Un systeme lineaire a soit aucune solution, soit exactement une solution, soit une infinite de solutions. Il n'existe jamais un systeme avec exactement deux solutions.

Theoreme de Rouche-Capelli : le systeme AX = b admet au moins une solution si et seulement si rang(A) = rang([A | b]). Dans ce cas, si ce rang vaut n (le nombre d'inconnues), la solution est unique ; sinon il y a une infinite de solutions, dependant de n - rang parametres libres.

Exemple de systeme incompatible : x + y = 1 et x + y = 3. Les deux equations se contredisent, donc il n'y a aucune solution. Le rang de A vaut 1 mais celui de la matrice augmentee vaut 2.

Exemple de systeme avec une infinite de solutions : x + y = 2 et 2x + 2y = 4. La seconde equation est le double de la premiere. Les solutions sont les couples (t, 2 - t) pour tout reel t : un parametre libre.

Systeme homogene : un systeme AX = 0 admet toujours la solution nulle. Il admet d'autres solutions si et seulement si det(A) = 0 (pour A carree).

======================================================================
5. DECOMPOSITION LU ET CONSIDERATIONS NUMERIQUES
======================================================================

La decomposition LU ecrit A = L x U, ou L est triangulaire inferieure (avec des 1 sur la diagonale) et U triangulaire superieure. Elle correspond a la methode de Gauss "memorisee". Une fois A decomposee, resoudre AX = b se fait en deux etapes simples : LY = b (descente), puis UX = Y (remontee). C'est tres avantageux lorsqu'on doit resoudre plusieurs systemes avec la meme matrice A mais des seconds membres differents.

Le cout de la factorisation LU d'une matrice n x n est d'environ (2/3) x n^3 operations. Chaque resolution supplementaire ne coute ensuite que de l'ordre de n^2 operations.

Pivotage partiel : pour limiter les erreurs d'arrondi, on choisit a chaque etape comme pivot le coefficient de plus grande valeur absolue dans la colonne, en echangeant les lignes si necessaire. Sans cette precaution, un pivot tres petit peut amplifier fortement les erreurs.

Conditionnement : une matrice dont le determinant est proche de 0 est dite mal conditionnee. De petites variations sur b peuvent alors provoquer de grandes variations sur la solution.
