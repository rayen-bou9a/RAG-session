Microsoft Corporation is an American multinational corporation and technology conglomerate headquartered in Redmond, Washington.

Microsoft was founded by Bill Gates and Paul Allen on April 4, 1975. The original name of Microsoft before it became Microsoft was "Micro-Soft" (a portmanteau of microcomputer and software).

Microsoft's first hardware product release was the Z-80 SoftCard in 1980, a plug-in card for the Apple II computer that allowed it to run the CP/M operating system.

In June 2018, Microsoft announced it would acquire GitHub, the world's leading software development platform, for $7.5 billion in Microsoft stock. The acquisition was completed in October 2018.
